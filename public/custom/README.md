# Optional private media

This directory is intentionally empty in the public template.

Add your own files only when you enable the matching feature in
`src/config/experience.ts`:

- `intro-film.mp4`
- `intro-film-poster.jpg`
- `intro-film-last-frame.jpg`
- `background-music.mp3`

Before publishing, confirm that you have permission to distribute every file.
Do not commit private photos, licensed music, or media containing personal
metadata unless all affected people have explicitly agreed.
